# Паттерны xbsl-collab-add

Источники: `tools/vendor/pp/СистемаВзаимодействия/` (P1a), финальная выгрузка курса (P1b).

## P1a — Контекстное обсуждение (простой вариант)

Компонент виден автоматически, когда объект не новый и СВ подключена.  
Подходит для форм с `ШаблонФормыСРазделами`.

### YAML — добавить в `ДополнительныеРазделы`

```yaml
        -
            Тип: Группа
            Заголовок: Обсуждение
            Содержимое:
                -
                    Тип: КомпонентОбсуждения
                    Имя: КомпонентОбсуждения
                    РастягиватьПоВертикали: Истина
                    Видимость: =не ЭтоНовый() и СистемаВзаимодействия.ИспользованиеДоступно()
```

Если секции `ДополнительныеРазделы` нет — добавить после блока `ОсновнойРаздел`:

```yaml
        ДополнительныеРазделы:
            -
                Тип: Группа
                Заголовок: Обсуждение
                Содержимое:
                    -
                        Тип: КомпонентОбсуждения
                        Имя: КомпонентОбсуждения
                        РастягиватьПоВертикали: Истина
                        Видимость: =не ЭтоНовый() и СистемаВзаимодействия.ИспользованиеДоступно()
```

### XBSL — метод `ПослеЧтения`

```
@Обработчик
метод ПослеЧтения()
    если СистемаВзаимодействия.ИспользованиеДоступно() и не Объект.ЭтоНовый()
        Компоненты.КомпонентОбсуждения.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ;
;
```

Если в `.xbsl` уже есть `ПослеЧтения` — добавить строки внутрь существующего метода (перед закрывающей `;`).

## P1b — Контекстное обсуждение с кнопкой активации

Пользователь видит надпись «Открыть чат» и явно открывает переписку.  
Подходит для форм с `ШаблонФормыСРазделами`.

### YAML — добавить в `ДополнительныеРазделы`

```yaml
        -
            Тип: Группа
            Имя: ГруппаЧата
            Доступность: =не ЭтоНовый()
            Заголовок: Чат
            Компоновка: Вертикальная
            РастягиватьПоВертикали: Истина
            РастягиватьПоГоризонтали: Истина
            Содержимое:
                -
                    Тип: КомпонентОбсуждения
                    Имя: Чат
                    Видимость: =ПоказатьЧат
                    РастягиватьПоВертикали: Истина
                    РастягиватьПоГоризонтали: Истина
                -
                    Тип: Надпись
                    Имя: НадписьПоказатьЧат
                    Видимость: =не ПоказатьЧат
                    ВыравниваниеВГруппеПоВертикали: Центр
                    ВыравниваниеВГруппеПоГоризонтали: Центр
                    ВыравниваниеСодержимогоПоВертикали: Центр
                    ВыравниваниеСодержимогоПоГоризонтали: Центр
                    Значение: "Открыть чат"
                    Изображение: ЧатКонтур.svg
                    ОбрабатыватьНажатие: Истина
                    ПриНажатии: НадписьПоказатьЧатПриНажатии
                    РастягиватьПоВертикали: Auto
                    РастягиватьПоГоризонтали: Auto
```

### YAML — добавить реквизит в `Свойства` формы

```yaml
    -
        Имя: ПоказатьЧат
        Тип: Булево
```

Если секции `Свойства` в форме нет — добавить перед последней строкой файла:

```yaml
Свойства:
    -
        Имя: ПоказатьЧат
        Тип: Булево
```

### XBSL — методы `ПослеЧтения` и `НадписьПоказатьЧатПриНажатии`

```
@Обработчик
метод ПослеЧтения()
    если СистемаВзаимодействия.ИспользованиеДоступно() и не Объект.ЭтоНовый()
        Компоненты.Чат.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ;
;

метод НадписьПоказатьЧатПриНажатии(Источник: Надпись, Событие: СобытиеПриНажатии)
    Компоненты.Чат.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ПоказатьЧат = Истина
;
```

---

## Заметки

**`КлючОбъекта`** — встроенное свойство формы объекта, передаётся в `УстановитьКонтекстОбсуждения` как идентификатор для привязки обсуждения. Не путать с `ЭтотОбъект.Ссылка`.

**`СистемаВзаимодействия.ИспользованиеДоступно()`** — возвращает `Истина` только если приложение зарегистрировано в 1С-диалог. Без этой проверки компонент вызовет ошибку в незарегистрированном приложении.

**`ПроизвольныйШаблонФормы`** — `ДополнительныеРазделы` недоступны. Предупреди пользователя и предложи добавить `КомпонентОбсуждения` вручную в нужное место `Содержимое` формы.

**Иконка `ЧатКонтур.svg`** (P1b) — встроенный ресурс платформы, не нужно добавлять в папку `Ресурсы` проекта.
