Источники: `tools/vendor/pp/СистемаВзаимодействия/` (P1a), финальная выгрузка курса (P1b/P2/P3).

## P1a — Контекстное обсуждение (простой вариант)

Компонент виден автоматически, когда объект не новый и СВ подключена.  
Подходит для форм с `ШаблонФормыСРазделами`.

### YAML — добавить в `ДополнительныеРазделы`

```yaml
        -
            Тип: Группа
            Заголовок: Обсуждение
            Содержимое:
                -
                    Тип: КомпонентОбсуждения
                    Имя: КомпонентОбсуждения
                    РастягиватьПоВертикали: Истина
                    Видимость: =не ЭтоНовый() и СистемаВзаимодействия.ИспользованиеДоступно()
```

Если секции `ДополнительныеРазделы` нет — добавить после блока `ОсновнойРаздел`:

```yaml
        ДополнительныеРазделы:
            -
                Тип: Группа
                Заголовок: Обсуждение
                Содержимое:
                    -
                        Тип: КомпонентОбсуждения
                        Имя: КомпонентОбсуждения
                        РастягиватьПоВертикали: Истина
                        Видимость: =не ЭтоНовый() и СистемаВзаимодействия.ИспользованиеДоступно()
```

### XBSL — метод `ПослеЧтения`

```
@Обработчик
метод ПослеЧтения()
    если СистемаВзаимодействия.ИспользованиеДоступно() и не Объект.ЭтоНовый()
        Компоненты.КомпонентОбсуждения.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ;
;
```

Если в `.xbsl` уже есть `ПослеЧтения` — добавить строки внутрь существующего метода (перед закрывающей `;`).

## P1b — Контекстное обсуждение с кнопкой активации

Пользователь видит надпись «Открыть чат» и явно открывает переписку.  
Подходит для форм с `ШаблонФормыСРазделами`.

### YAML — добавить в `ДополнительныеРазделы`

```yaml
        -
            Тип: Группа
            Имя: ГруппаЧата
            Доступность: =не ЭтоНовый()
            Заголовок: Чат
            Компоновка: Вертикальная
            РастягиватьПоВертикали: Истина
            РастягиватьПоГоризонтали: Истина
            Содержимое:
                -
                    Тип: КомпонентОбсуждения
                    Имя: Чат
                    Видимость: =ПоказатьЧат
                    РастягиватьПоВертикали: Истина
                    РастягиватьПоГоризонтали: Истина
                -
                    Тип: Надпись
                    Имя: НадписьПоказатьЧат
                    Видимость: =не ПоказатьЧат
                    ВыравниваниеВГруппеПоВертикали: Центр
                    ВыравниваниеВГруппеПоГоризонтали: Центр
                    ВыравниваниеСодержимогоПоВертикали: Центр
                    ВыравниваниеСодержимогоПоГоризонтали: Центр
                    Значение: "Открыть чат"
                    Изображение: ЧатКонтур.svg
                    ОбрабатыватьНажатие: Истина
                    ПриНажатии: НадписьПоказатьЧатПриНажатии
                    РастягиватьПоВертикали: Auto
                    РастягиватьПоГоризонтали: Auto
```

### YAML — добавить реквизит в `Свойства` формы

```yaml
    -
        Имя: ПоказатьЧат
        Тип: Булево
```

Если секции `Свойства` в форме нет — добавить перед последней строкой файла:

```yaml
Свойства:
    -
        Имя: ПоказатьЧат
        Тип: Булево
```

### XBSL — методы `ПослеЧтения` и `НадписьПоказатьЧатПриНажатии`

```
@Обработчик
метод ПослеЧтения()
    если СистемаВзаимодействия.ИспользованиеДоступно() и не Объект.ЭтоНовый()
        Компоненты.Чат.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ;
;

метод НадписьПоказатьЧатПриНажатии(Источник: Надпись, Событие: СобытиеПриНажатии)
    Компоненты.Чат.УстановитьКонтекстОбсуждения(КлючОбъекта)
    ПоказатьЧат = Истина
;
```

## P2 — Группа управления СВ в панели навигации

Одноразовая настройка приложения. Добавляет пункты управления Системой взаимодействия в навигацию.

### YAML — добавить в конец `Элементы` файла навигации (или inline в YAML приложения)

```yaml
    -
        Тип: ГруппаКомандногоИнтерфейса
        Изображение: Чат.svg
        Представление: Система взаимодействия
        Элементы:
            -
                Тип: НавигационнаяКоманда
                Представление: Подключение
                ТипФормы: ФормаРегистрацииСистемыВзаимодействия
            -
                Тип: НавигационнаяКоманда
                Представление: Управление
                ТипФормы: ФормаУправленияСистемойВзаимодействия
            -
                Тип: НавигационнаяКоманда
                Представление: Веб-чат
                ТипФормы: ФормаРегистрацииВебЧата
            -
                Тип: НавигационнаяКоманда
                Представление: Интеграции
                ТипФормы: ФормаИнтеграцийСистемыВзаимодействия
```

Если навигация в отдельном файле (`nav_is_inline: false`) — добавить в конец `Элементы:` этого файла.  
Если навигация inline (`nav_is_inline: true`) — добавить в конец `Элементы:` внутри секции `КомандныйИнтерфейсПанелиНавигации` YAML приложения (с соответствующим отступом +8 от корня).

## P3 — Веб-чат виджет

Одноразовая настройка приложения. Включает плавающий чат-виджет для пользователей.

### YAML — добавить в блок `Наследует:` YAML приложения

Вставить сразу после строки `Тип: СтандартноеКлиентскоеПриложениеСРазделами`:

```yaml
    ВебЧат:
        Использовать: Истина
        ПриПолученииДанныхПользователя: ВебЧатПриПолученииДанных
```

### XBSL — метод `ВебЧатПриПолученииДанных`

Добавить в `.xbsl` компонента приложения (создать файл, если не существует):

```
метод ВебЧатПриПолученииДанных(Источник: ВебЧат, Событие: СобытиеПриПолученииДанныхПользователяВебЧата)
    Событие.ПолноеИмя = ПользователиКлиентИСервер.ПолучитьДанныеТекущегоПользователя().Пользователь.Представление()
;
```

Если в `.xbsl` уже есть `импорт` другого модуля — добавить строку рядом. Если файла нет — создать с нужным `импорт <Подсистема>`.

## Заметки

**`КлючОбъекта`** — встроенное свойство формы объекта, передаётся в `УстановитьКонтекстОбсуждения` как идентификатор для привязки обсуждения. Не путать с `ЭтотОбъект.Ссылка`.

**`СистемаВзаимодействия.ИспользованиеДоступно()`** — возвращает `Истина` только если приложение зарегистрировано в 1С-диалог. Без этой проверки компонент вызовет ошибку в незарегистрированном приложении.

**`ПроизвольныйШаблонФормы`** — `ДополнительныеРазделы` недоступны. Предупреди пользователя и предложи добавить `КомпонентОбсуждения` вручную в нужное место `Содержимое` формы.

**Иконка `ЧатКонтур.svg`** (P1b) — встроенный ресурс платформы, не нужно добавлять в папку `Ресурсы` проекта.

**Иконка `Чат.svg`** (P2) — встроенный ресурс платформы, не нужно добавлять в папку `Ресурсы` проекта.

**`ПользователиКлиентИСервер`** (P3) — общий модуль проекта. Нужен `импорт <Подсистема>` с этим модулем в `.xbsl` приложения. Если модуля нет — заменить строку `Событие.ПолноеИмя = ...` на нужный способ получить отображаемое имя текущего пользователя.
