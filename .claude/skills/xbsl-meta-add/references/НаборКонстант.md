# Спецификация: НаборКонстант

## Назначение

Факты платформы:

- `ВидЭлемента: НаборКонстант` описывает набор постоянных значений приложения.
- Источники различают непериодический и периодический наборы.

Соглашения генератора:

- Имя задавай PascalCase, существительное во множественном числе.

## Версия

- Минимальная версия платформы: 9.1+.

## YAML

Required:

```yaml
ВидЭлемента: НаборКонстант
Ид: <UUID>
Имя: <Имя>
ОбластьВидимости: ВПодсистеме
Периодичность: Непериодический
Константы:
    -
        Ид: <UUID>
        Имя: <ИмяКонстанты>
        Тип: <Тип>
```

Negative:

- Не смешивай контракты периодического и непериодического варианта.
- Не используй API непериодического варианта для периодического набора без отдельного источника.

## UUID

Required:

- UUID получает объект набора констант.
- UUID получает каждый элемент `Константы[]`.

Negative:

- Не засчитывай только количество UUID; проверяй, что UUID стоят именно на объекте и константах.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.
- Ссылочные типы в `Константы[].Тип` проверяй по `references/types.md` и межподсистемному workflow.

Negative:

- Не поднимай видимость ссылочного объекта без фактической межподсистемной ссылки.

## Companion artifacts

Required:

- `*.yaml` - описание объекта.

Negative:

- XBSL не является обязательным companion минимального объекта.

## Генерация

Required:

- Skill создает один YAML для выбранного варианта периодичности.
- Если пользователь не указал периодичность, используй `Непериодический`.

Negative:

- Не создавай API-пример без явного запроса пользователя.

## Валидация

Required:

- `Константы` непустой список.
- Каждый элемент `Константы[]` содержит `Ид`, `Имя`, `Тип`.
- `Периодичность` явно отражает выбранный вариант.

Negative:

- `periodic_nonperiodic_api_mix`.
