# Спецификация: Обработка

## Назначение

Platform facts:

- `ВидЭлемента: Обработка` описывает исполняемый объект с операциями.
- Для операции нужен одноименный обработчик в XBSL-модуле.

Local conventions:

- Имя задавай PascalCase, существительное или действие по смыслу обработки.
- Минимальный комплект содержит одну операцию и одноименный метод.

## YAML

Required:

```yaml
ВидЭлемента: Обработка
Ид: <UUID>
Имя: <Имя>
ОбластьВидимости: ВПодсистеме
Операции:
    -
        Имя: <ИмяОперации>
        Представление: <Представление>
```

Negative:

- Не объявляй операцию без одноименного метода.
- Не добавляй форму как обязательное свойство минимального комплекта.

## UUID

Required:

- UUID получает объект обработки.
- Подтвержденная минимальная запись `Операции[]` не требует собственного UUID.

Negative:

- Не добавляй UUID операции без source-backed требования.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.
- Импорты нужны только при обращении к объектам внешних подсистем из YAML или модуля.

Negative:

- Не расширяй видимость обработки только из-за наличия операции.

## Companion artifacts

Required:

- `*.yaml` - описание объекта.
- `*.Объект.xbsl` - обязательный модуль объекта с обработчиками операций.

Negative:

- Отсутствующий модуль или метод с другим именем не закрывает контракт операции.

## Генерация

Required:

- Skill создает `<Имя>.yaml` и `<Имя>.xbsl`.
- Для каждой операции генерируется метод с `@Обработчик`.

Negative:

- Повторный запуск не должен дублировать уже существующий обработчик.

## Валидация

Required:

- `set(Операции[].Имя)` является подмножеством методов с `@Обработчик`.
- Модуль находится рядом с YAML и называется `<Имя>.Объект.xbsl`.

Negative:

- `missing_handler`, `wrong_handler_name`.

## Runtime evidence

Required:

- `object-coverage.json` фиксирует passed runtime check: 1cmycloud `test-app`, technology build `9.2.9-12`, assembly `TestApp 1.0-216.xasm`, image `019fa958-8ab0-70be-a647-735da5c7ec90`, update task `019fa958-8df1-7fbe-b1fc-a7191da92c5` completed on `2026-07-28`.

Negative:
