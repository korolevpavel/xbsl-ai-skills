# Спецификация: ПараметрСамостоятельнойРегистрацииПользователя

## Назначение

Platform facts:

- `ВидЭлемента: ПараметрСамостоятельнойРегистрацииПользователя` передает
  процессу самостоятельной регистрации данные, подготовленные до начала
  регистрации.
- `Поля[]` описывает поля параметра; подтвержденный пример использует `Имя` и
  `Тип`.
- Элемент имеет предопределенные обработчики: `ПослеПодключения()` обязателен,
  `ПриПроверкеПараметра(Логин: Строка?, Контакты: ЧитаемоеСоответствие<ВидКонтактаПользователя, Строка>): Булево`
  необязателен.

Local conventions:

- Минимальная генерация не создает форму регистрации, пользователя, роль,
  список пользователей или настройки контроля доступа.
- Модуль-скелет обязан быть безопасным и не менять production state.

## YAML

Required:

```yaml
ВидЭлемента: ПараметрСамостоятельнойРегистрацииПользователя
Ид: <UUID>
Имя: <ИмяПараметра>
ОбластьВидимости: ВПодсистеме
Поля:
    -
        Имя: <ИмяПоля>
        Тип: <Тип>
```

Negative:

- Не добавляй `Ид` внутрь `Поля[]`, пока отдельный source не подтвердит такое
  свойство.
- Не создавай UI-компонент или настройки самостоятельной регистрации как
  companion этого объекта.

## UUID

Required:

- UUID получает сам объект
  `ПараметрСамостоятельнойРегистрацииПользователя`.

Negative:

- `Поля[]` в подтвержденных примерах не получают собственного UUID.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно; подтвержденные примеры используют
  `ВПодсистеме`.
- `Импорт` добавляй только для типов из внешних пространств имен.

Negative:

- Не добавляй `Импорт` для встроенных типов `Строка`, `Дата` или `Ууид`.

## Companion artifacts

Required:

- `*.yaml` - описание параметра самостоятельной регистрации.
- `*.xbsl` - одноименный модуль с обязательным обработчиком
  `ПослеПодключения()`.

Negative:

- `ПриПроверкеПараметра(...)` не является обязательным обработчиком.
- Форма регистрации и клиентское приложение не являются обязательными
  companion-артефактами этого объекта.

## Генерация

Required:

- Skill создает `<Имя>.yaml` и `<Имя>.xbsl`.
- Модуль содержит `@Обработчик` и `метод ПослеПодключения()`.
- Опциональный `ПриПроверкеПараметра(...)` добавляй только по запросу
  пользователя.

Local conventions:

- В безопасном skeleton `ПослеПодключения()` оставляй без действий, если
  пользователь не описал нужное подключение.

Negative:

- Не записывай пользователя, роль, список пользователей или объект приложения
  без явного запроса и проверки проекта.

## Валидация

Required:

- `ВидЭлемента` равен
  `ПараметрСамостоятельнойРегистрацииПользователя`.
- `Поля[]` непустой список с `Имя` и `Тип`.
- Одноименный модуль содержит обязательный обработчик `ПослеПодключения()`.

Negative:

- `missing_required_handler`.
