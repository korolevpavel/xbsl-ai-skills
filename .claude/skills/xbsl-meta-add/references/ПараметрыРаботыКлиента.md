# Спецификация: ПараметрыРаботыКлиента

## Назначение

Platform facts:

- `ВидЭлемента: ПараметрыРаботыКлиента` доступен с платформы 9.2.
- Объект описывает параметры, вычисляемые на сервере и доступные клиентскому коду.
- Вложенные элементы `Параметры[]` не имеют собственного `Ид`.

Local conventions:

- Имя задавай PascalCase по набору стартовых параметров.
- Модуль создавай рядом с YAML и называй `<Имя>.xbsl`.

## YAML

Required:

```yaml
ВидЭлемента: ПараметрыРаботыКлиента
Ид: <UUID>
Имя: <Имя>
ОбластьВидимости: ВПроекте
Параметры:
    -
        Имя: <ИмяПараметра>
        Тип: <ТипПередаваемыйСКлиента>
```

Negative:

- Не добавляй `Ид` в элементы `Параметры[]`.
- Не используй типы, которые не передаются с сервера на клиент.

## UUID

Required:

- UUID получает объект `ПараметрыРаботыКлиента`.
- Вложенные параметры не получают UUID.

Negative:

- `Ид` внутри `Параметры[]` является ошибкой контракта.

## Imports и visibility

Required:

- `ОбластьВидимости: ВПроекте` для доступа клиентского кода.
- Типы параметров выбирай из клиентски передаваемых типов.

Negative:

- Не используй серверные потоковые и файловые типы как параметры.

## Companion artifacts

Required:

- `*.yaml` - описание объекта.
- `*.xbsl` - обязательный одноименный модуль с вычислением параметров.

Negative:

- Отсутствующий или неверно названный обработчик не закрывает контракт.

## Генерация

Required:

- Skill создает `<Имя>.yaml` и `<Имя>.xbsl`.
- Модуль содержит `@Обработчик`, `@НаСервере` и статический метод `ВычислитьПараметрыРаботыКлиента(): <Имя>.Параметры`.

Negative:

- Не добавляй неподтвержденные свойства singleton или retry в YAML.

## Валидация

Required:

- `Параметры` непустой список.
- Каждый параметр содержит `Имя` и `Тип`, без `Ид`.
- Модуль содержит точный обработчик `ВычислитьПараметрыРаботыКлиента`.

Negative:

- `nested_parameter_id`, `non_client_type`, `wrong_handler`.
