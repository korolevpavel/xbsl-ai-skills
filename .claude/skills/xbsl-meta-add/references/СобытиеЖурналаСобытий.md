# Спецификация: СобытиеЖурналаСобытий

## Назначение

Platform facts:

- `ВидЭлемента: СобытиеЖурналаСобытий` описывает событие для журнала событий.
- `ВидСобытия` принимает `Информация`, `Ошибка` или `Операция`; default:
  `Информация`.
- `Важность` принимает значения важности события или `ИзКонструктора`;
  default: `ИзКонструктора`.
- `Свойства[]` описывает свойства события, которые отображаются на свойства в
  языке.

Local conventions:

- Минимальная генерация создает только YAML и не пишет события в журнал.
- XBSL API регистрации события не выводится из YAML-страницы.

## YAML

Required:

```yaml
ВидЭлемента: СобытиеЖурналаСобытий
Ид: <UUID>
Имя: <ИмяСобытия>
ОбластьВидимости: ВПодсистеме
ВидСобытия: Информация
ШаблонПредставления: <Форматная строка>
```

Optional:

- Для `ВидСобытия: Ошибка` укажи `ХарактерОшибки`.
- Для `ВидСобытия: Операция` укажи `ШаблонПредставленияНачала`,
  `ШаблонПредставленияКонца` и `ШаблонПредставленияОшибки`.
- `Свойства[]` может содержать `Ид`, `Имя`, `Тип`, `Обязательное`,
  `ЗначениеПоУмолчанию` и `Описание`.

Negative:

- Не заявляй функцию, receiver, параметры или возвращаемый тип XBSL API без
  отдельного источника.
- Для операции не пропускай обязательные шаблоны начала, конца и ошибки.

## UUID

Required:

- UUID получает сам объект `СобытиеЖурналаСобытий`.
- Каждый элемент `Свойства[]` получает собственный UUID.

Negative:

- Не добавляй UUID для шаблонов представления.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно; default платформы: `ВПодсистеме`.
- `Импорт` добавляй только для типов из внешних пространств имен.

Negative:

- Не добавляй `Импорт` для встроенных типов `Строка`, `Число`, `Булево`,
  `Момент`, `Длительность`, `Ууид`.

## Companion artifacts

Required:

- `*.yaml` - описание события журнала событий.

Negative:

- `.xbsl` не является обязательным companion: тематический источник описывает
  YAML-свойства, но не сигнатуру API регистрации события.

## Генерация

Required:

- Skill создает `<Имя>.yaml`.
- Для `Операция` генерируй все три шаблона представления.

Local conventions:

- Имена событий задавай как факт или операция: `ОперацияИмпортаДанных`,
  `ОшибкаИмпорта`.

Negative:

- Не создавай обработчик или вызов записи события без отдельного запроса и
  отдельного источника.

## Валидация

Required:

- `ВидЭлемента` равен `СобытиеЖурналаСобытий`.
- `ВидСобытия: Операция` содержит `ШаблонПредставленияНачала`,
  `ШаблонПредставленияКонца` и `ШаблонПредставленияОшибки`.
- Свойства события имеют уникальные `Имя`.

Negative:

- `operation_event_missing_templates`.
