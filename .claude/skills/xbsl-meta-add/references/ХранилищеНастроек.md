# Спецификация: ХранилищеНастроек

## Назначение

Факты платформы:

- `ВидЭлемента: ХранилищеНастроек` описывает объект хранения настроек.
- Документированный API доступен через stdlib-контракт хранилища настроек.

Соглашения генератора:

- Имя задавай PascalCase, по области настроек.
- форма не является обязательным companion для минимального объекта.
- модуль не является обязательным companion для минимального объекта.

## Версия и источники

| Claim | Источник | Проверено | Что подтверждает |
| --- | --- | --- | --- |
| YAML-схема хранилища настроек | `topics/latest/settings-repository` | 2026-07-28 | `ВидЭлемента` и стандартные свойства |
| Stdlib API хранилища настроек | `stdlib/latest/element/xbsl/Std/SettingsStorages/SettingsStorage_ru` | 2026-07-28 | методы пересчета разрешений и стандартных значений выбора |

## YAML

Required:

```yaml
ВидЭлемента: ХранилищеНастроек
Ид: <UUID>
Имя: <Имя>
ОбластьВидимости: ВПодсистеме
```

Negative:

- Не добавляй `Интерфейс` как обязательный блок минимального объекта.
- Не требуй XBSL-модуль без отдельного source-backed требования.

## UUID

Required:

- UUID получает объект хранилища настроек.

Negative:

- Не добавляй UUID вложенным элементам, если они не присутствуют в выбранной подтвержденной схеме.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.
- Импорты нужны только при фактических ссылках на внешние подсистемы.

Negative:

- Не повышай область видимости ради необязательной формы.

## Companion artifacts

Required:

- `*.yaml` - описание объекта.

Negative:

- форма не является обязательным companion.
- модуль не является обязательным companion.
- XBSL API-пример не создается как пользовательский companion без явного запроса.

## Генерация

Required:

- Skill создает только YAML, если пользователь не попросил дополнительных UI/API файлов.
- Дополнительные API-файлы создавай только по явному запросу пользователя.

Negative:

- Не записывай API-пример без явного запроса пользователя.

## Валидация

Required:

- Минимальный YAML содержит `ВидЭлемента`, `Ид`, `Имя`, `ОбластьВидимости`.
- Required artifacts в registry равны только `*.yaml`.

Negative:

- Contract не должен требовать форму или модуль.
