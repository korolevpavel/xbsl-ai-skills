# Спецификация: ЦветоваяСхемаОтчета

## Назначение

Platform facts:

- `ВидЭлемента: ЦветоваяСхемаОтчета` задает цвета для отчетов и панелей
  отчетов.
- `Представление` является обязательным.
- `Цвета` имеет тип `Массив<АбсолютныйЦвет>`.
- Если `ЦветаТемнойТемы` не заполнен, используется список из `Цвета`.

Local conventions:

- Используй форму абсолютного цвета `RGB(RRGGBB)`.
- Не добавляй прямую YAML-ссылку цветовой схемы на объект `Отчет`.

## Версия и источники

| Claim | Источник | Проверено | Что подтверждает |
| --- | --- | --- | --- |
| YAML-свойства цветовой схемы отчета | `topics/latest/report-color-scheme` | 2026-07-29 | `ВидЭлемента`, `Представление`, `Цвета`, `ЦветаТемнойТемы`, fallback |

## YAML

Required:

```yaml
ВидЭлемента: ЦветоваяСхемаОтчета
Ид: <UUID>
Имя: <ИмяСхемы>
ОбластьВидимости: ВПодсистеме
Представление: <Название схемы>
Цвета:
    - RGB(009E73)
```

Optional:

- `ЦветаТемнойТемы` задает отдельный список цветов для темной темы.
- При отсутствии `ЦветаТемнойТемы` платформа использует `Цвета`.

Negative:

- Не используй `#RRGGBB` вместо `RGB(RRGGBB)`.
- Не добавляй ссылку на отчет в YAML схемы.

## UUID

Required:

- UUID получает объект `ЦветоваяСхемаОтчета`.

Negative:

- Элементы массива цветов не получают собственный UUID.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.

Negative:

- `Импорт` не нужен для массива абсолютных цветов.

## Companion artifacts

Required:

- `*.yaml` - описание цветовой схемы отчета.

Negative:

- Обязательных companion-файлов нет.

## Генерация

Required:

- Skill создает один YAML.
- При запросе темной темы добавляет `ЦветаТемнойТемы`; иначе оставляет
  source-backed fallback.

Local conventions:

- Цвета сохраняй в верхнем регистре шестнадцатеричных цифр.

Negative:

- Не создавай XBSL, форму или report reference для цветовой схемы.

## Валидация

Required:

- `Цвета` содержит элементы формата `RGB(RRGGBB)`.
- `ЦветаТемнойТемы`, если присутствует, имеет тот же формат элементов.

Negative:

- `invalid_absolute_color`.
