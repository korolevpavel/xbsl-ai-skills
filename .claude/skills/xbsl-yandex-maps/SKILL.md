# xbsl-yandex-maps

Скилл добавляет интерактивную Яндекс.Карту в форму объекта 1С:Элемент.
Нативная поддержка Яндекс.Карт в платформе не реализована — скилл использует внешнюю библиотеку.

**Дефолтная библиотека:** https://github.com/korolevpavel/xbsl-yandex-maps

---

## Шаг 0 — Извлечь параметры из запроса

Из запроса пользователя определить:

- **ИмяОбъекта** — имя справочника или документа (например, `Склады`)
- **ТипФормы** — по умолчанию `ФормаОбъекта`
- **ПолеАдреса** — поле объекта с адресом (если указано явно)
- **ВысотаКарты** — высота блока карты в px (по умолчанию `400`)

---

## Шаг 1 — Предложить варианты пользователю

Сообщить:

> **Нативная поддержка Яндекс.Карт в 1С:Элемент пока не реализована.**
>
> Доступны два варианта:
> 1. **Подключить через внешнюю библиотеку** — интерактивная карта через библиотеку ЯндексКарты (рекомендуется)
> 2. **Ничего не делать** — вернуться к этому позже, когда появится нативная поддержка

Спросить пользователя о выборе.

**Если выбран вариант 2** → завершить:
> "Когда платформа добавит нативную поддержку Яндекс.Карт, вы сможете повторно обратиться к этому скиллу."

---

## Шаг 2 — Найти объект и проверить наличие библиотеки

Запустить разведку для нахождения объекта:

```bash
python3 .claude/skills/xbsl-explore/scripts/explore.py \
    --type Справочник --name {ИмяОбъекта} --root .
```

Если тип объекта не Справочник — подобрать нужный (Документ и т.д.).

Из результата извлечь `project_yaml_path` (путь к `Проект.yaml`). Прочитать его.

Проверить наличие библиотеки ЯндексКарты в разделе `Библиотеки`:
```yaml
Библиотеки:
  - Имя: ЯндексКарты
    ...
```

- Если библиотека **уже подключена** → перейти к Шагу 4.
- Если **не подключена** → перейти к Шагу 3.

---

## Шаг 3 — Подключить библиотеку через xbsl-lib-connect

Спросить пользователя об источнике библиотеки:

> Укажите источник библиотеки ЯндексКарты.
> По умолчанию: https://github.com/korolevpavel/xbsl-yandex-maps
> (нажмите Enter для использования дефолтного или укажите свой .xlib / URL / папку)

Вызвать скилл подключения:
```
Skill("xbsl-lib-connect")
```

Передать полученный источник в скилл. Следовать всем шагам xbsl-lib-connect.

Если подключение завершилось с ошибкой → сообщить об ошибке и остановиться.

После успешного подключения прочитать обновлённый `Проект.yaml`, извлечь
`LIB_VENDOR` и `LIB_NAME` из добавленной записи в `Библиотеки`.

python3 .claude/skills/xbsl-form-info/scripts/form_info.py \

Из JSON-ответа извлечь:

## Шаг 5 — Определить поле адреса

Если `ПолеАдреса` не указано в запросе пользователя:

1. Искать среди `fields` поля типа `Строка` с именами (без учёта регистра):
   `Адрес`, `ПолныйАдрес`, `МестоНахождение`, `Местоположение`, `Location`, `Address`
2. Найден **один кандидат** → использовать его автоматически, сообщить пользователю
3. Найдено **несколько** или **ни одного** → спросить:
   > "Укажите реквизит объекта, содержащий адрес для отображения на карте (или введите `нет` если поле адреса ещё не создано):"

## Шаг 7 — Добавить компонент карты в форму

Сгенерировать UUID для нового компонента `КонтейнерHtml`:
```
Skill("xbsl-uuid")
```

**YAML-блок компонента** (взять из reference-файла, подставить `{ВысотаКарты}`):
```yaml
-
    Тип: КонтейнерHtml
    Имя: КартаЯндекс
    БезопасныйРежим: Ложь
    ПослеЗагрузкиСодержимого: КартаЯндексПослеЗагрузки
    МинимальнаяВысота: {ВысотаКарты}
    РастягиватьПоГоризонтали: Истина
```

### Если ФормаОбъекта уже существует

Прочитать файл `{object_path}/ФормаОбъекта.yaml`.
Найти `Содержимое:` верхней группы (обычно `ПроизвольныйШаблонФормы` → `Группа`).
Вставить блок `КонтейнерHtml` после последнего реквизитного поля (перед командами или в конце).

Если в YAML формы нет секции `Использование:` — проверить, является ли модуль
библиотеки `@Глобально`. Если нет — добавить:
```yaml
Использование:
    - {LIB_VENDOR}::{LIB_NAME}::Основное
```

### Если ФормаОбъекта НЕ существует

Создать файл `{object_path}/ФормаОбъекта.yaml` с минимальной структурой,
содержащей только `КонтейнерHtml`. Структура:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: {UUID}
Имя: ФормаОбъекта
ОбластьВидимости: ВПодсистеме
Наследует:
    Тип: ФормаОбъекта<{ИмяОбъекта}.Объект>
    ВключатьВАвтоИнтерфейс: Истина
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Компоновка: Вертикальная
            Содержимое:
                -
                    Тип: КонтейнерHtml
                    Имя: КартаЯндекс
                    БезопасныйРежим: Ложь
                    ПослеЗагрузкиСодержимого: КартаЯндексПослеЗагрузки
                    МинимальнаяВысота: {ВысотаКарты}
                    РастягиватьПоГоризонтали: Истина
```

## Шаг 8 — Создать/дополнить .xbsl файл формы

Загрузить шаблоны XBSL из `references/карта-форма-объекта.md`.

Подставить в шаблоны реальное имя поля: `{ПолеАдреса}`.

**Если `{object_path}/ФормаОбъекта.xbsl` НЕ существует** — создать:

```xbsl
метод ПослеСоздания()
    Компоненты.КартаЯндекс.Содержимое = ЯндексКарты.СформироватьHtmlКарты(Объект.{ПолеАдреса})
;

метод КартаЯндексПослеЗагрузки(Источник: КонтейнерHtml, Событие: СобытиеКомпонента)
;
```

**Если файл уже существует** — прочитать его, затем:
- Если метод `ПослеСоздания` отсутствует → добавить в конце файла
- Если метод `ПослеСоздания` уже есть → вставить строку с `Компоненты.КартаЯндекс.Содержимое`
  в начало тела метода
- В обоих случаях добавить метод `КартаЯндексПослеЗагрузки` если его нет
