# Карта Яндекс в ФормаОбъекта: шаблоны YAML и XBSL

Библиотека `korolevpavel::YandexMaps` предоставляет готовый компонент **`КартаЯндекса`**
(`КомпонентИнтерфейса`, `ОбластьВидимости: Глобально`). Не нужен `КонтейнерHtml` вручную.

---

## Секция 1: Импорт и свойства формы

Добавить в верхний уровень YAML формы (до `Наследует:`):

```yaml
Импорт:
    - korolevpavel::YandexMaps::Основное
Свойства:
    -
        Имя: МеткиКарты
        Тип: Массив<МеткаКарты>
```

---

## Секция 2: YAML-компонент КартаЯндекса

Вставить в `Содержимое` формы (полная ширина — `ШиринаВКолонках: Двойная`):

```yaml
-
    Тип: КартаЯндекса
    Имя: Карта
    Метки: =МеткиКарты
    АвтоПодобратьГраницы: Истина          # автоматически подбирает масштаб под метки
    КластеризоватьМетки: Истина
    РастягиватьПоГоризонтали: Истина
    Высота: 400                             # подобрать по UX, обычно 300–500
    ШиринаВКолонках: Двойная               # полная ширина в сетке
```

**Свойства компонента `КартаЯндекса`:**
- `Метки` — `Массив<МеткаКарты>` — список меток на карте (обязательно)
- `ЦентрШирота`, `ЦентрДолгота` — явный центр карты (опционально, если `АвтоПодобратьГраницы: Ложь`)
- `Масштаб` — уровень зума (опционально)
- `АвтоПодобратьГраницы` — подстроить границы под метки (по умолчанию `Истина`)
- `КластеризоватьМетки` — кластеризация при большом числе меток (по умолчанию `Истина`)
- `ApiKey` — переопределить API-ключ из `НастройкиYandexMaps` (опционально)

## Секция 3: XBSL — поля координат и обновление карты

### Минимальный вариант (одна метка из полей Широта/Долгота)

```xbsl
импорт korolevpavel::YandexMaps::Основное

@Обработчик
метод ПослеСоздания()
    МеткиКарты = ПолучитьМетки()
;

метод ПолучитьМетки(): Массив<МеткаКарты>
    пер Метки = новый Массив<МеткаКарты>()
    если Объект.Широта != Неопределено и Объект.Долгота != Неопределено
        Метки.Добавить(новый МеткаКарты(
            Идентификатор = "объект",
            Широта = Объект.Широта,
            Долгота = Объект.Долгота,
            Заголовок = Объект.Наименование
        ))
    ;
    возврат Метки
;

метод КоординатыПриИзменении(Источник: ПолеВвода<Число?>, Событие: СобытиеПриИзменении<Число?>)
    МеткиКарты = ПолучитьМетки()
;
```

### Поля координат в YAML формы (добавить рядом с другими реквизитами)

```yaml
-
    Тип: ПолеВвода<Число?>
    Имя: Широта
    Значение: =Объект.Широта
    ПриИзменении: КоординатыПриИзменении
-
    Тип: ПолеВвода<Число?>
    Имя: Долгота
    Значение: =Объект.Долгота
    ПриИзменении: КоординатыПриИзменении
```

### Структура МеткаКарты

```
МеткаКарты:
    Идентификатор: Строка?    # уникальный id метки
    Широта: Число             # широта (обязательно)
    Долгота: Число            # долгота (обязательно)
    Заголовок: Строка         # подпись на карте
    Описание: Строка?         # дополнительное описание (опционально)
```

## Секция 4: Что добавить в Подсистема.yaml

В файл `Подсистема.yaml` подсистемы, содержащей форму, добавить в раздел `Использование`:

```yaml
Использование:
    - korolevpavel::YandexMaps::Основное
```

Без этого платформа выдаст ошибку: *"Подсистема не указана в качестве используемой"*.

---

## Секция 5: Что добавить в объект метаданных

Если у объекта ещё нет полей координат, добавить в `.yaml` объекта:

```yaml
-
    Ид: {UUID}
    Имя: Широта
    Тип: Число?
-
    Ид: {UUID}
    Имя: Долгота
    Тип: Число?
```

---

## Секция 5: Напоминание об API-ключе

После деплоя обязательно:

1. Открыть приложение
2. Перейти в **НаборКонстант → НастройкиYandexMaps**
3. Заполнить поле **ApiKey** ключом с https://developer.tech.yandex.ru/
4. Сохранить

Без API-ключа компонент показывает сообщение "Карта недоступна" вместо карты.
