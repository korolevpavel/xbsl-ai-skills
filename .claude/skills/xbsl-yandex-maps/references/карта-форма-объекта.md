# Карта Яндекс в ФормаОбъекта: шаблоны YAML и XBSL

## Секция 1: YAML-компонент КонтейнерHtml

Вставить в `Содержимое` формы (в `Группа` или напрямую в `ПроизвольныйШаблонФормы`):

```yaml
-
    Тип: КонтейнерHtml
    Имя: КартаЯндекс
    БезопасныйРежим: Ложь                             # обязательно: разрешает JS-скрипты
    ПослеЗагрузкиСодержимого: КартаЯндексПослеЗагрузки
    МинимальнаяВысота: 400                             # подобрать по UX, обычно 300–500
    РастягиватьПоГоризонтали: Истина
```

**Обязательные правила:**
- `БезопасныйРежим: Ложь` — без него JS Яндекс.Карт не выполнится
- `РастягиватьПоГоризонтали: Истина` — карта должна занимать всю ширину контейнера
- `МинимальнаяВысота` — без этого карта схлопнется в нулевую высоту

## Секция 2: XBSL-обработчики

### Минимальный вариант (только инициализация)

```xbsl
метод ПослеСоздания()
    Компоненты.КартаЯндекс.Содержимое = ЯндексКарты.СформироватьHtmlКарты(Объект.Адрес)
;

метод КартаЯндексПослеЗагрузки(Источник: КонтейнерHtml, Событие: СобытиеКомпонента)
;
```

### Расширенный вариант (с обновлением при изменении адреса)

```xbsl
метод ПослеСоздания()
    Компоненты.КартаЯндекс.Содержимое = ЯндексКарты.СформироватьHtmlКарты(Объект.Адрес)
;

метод АдресПриИзменении(Поле: ПолеВвода)
    Компоненты.КартаЯндекс.Содержимое = ЯндексКарты.СформироватьHtmlКарты(Объект.Адрес)
;

метод КартаЯндексПослеЗагрузки(Источник: КонтейнерHtml, Событие: СобытиеКомпонента)
    // Вызывается после рендера HTML карты в iframe.
    // Здесь можно взаимодействовать с картой через JS:
    // Источник.УстановитьПеременную("window.mapVar.name", значение)
    // Источник.ВызватьМетод("functionName", [аргументы])
;
```

### Как подключить `АдресПриИзменении` к полю в YAML

В YAML-форме у поля адреса добавить `ПриИзменении`:

```yaml
-
    Тип: ПолеВвода
    Имя: Адрес
    Значение: =Объект.Адрес
    ПриИзменении: АдресПриИзменении
```

## Секция 3: Импорт библиотеки

Если `ОбщийМодуль ЯндексКарты` в библиотеке помечен `@Глобально` — импорт не нужен,
модуль доступен напрямую.

Если модуль НЕ глобальный — добавить в `.yaml` файл формы или подсистемы:

```yaml
Использование:
    - {LIB_VENDOR}::{LIB_NAME}::Основное
```

Реальные значения `LIB_VENDOR` и `LIB_NAME` берутся из записи в `Проект.yaml`,
которую добавил xbsl-lib-connect.

## Секция 4: Напоминание об API-ключе

После деплоя обязательно:

1. Открыть приложение
2. Перейти в **НаборКонстант → ЯндексКартыНастройки**
3. Заполнить поле **АПИКлючЯндекса** ключом с https://developer.tech.yandex.ru/
4. Сохранить

Без API-ключа карта отображается с ограничениями или не отображается вовсе.
