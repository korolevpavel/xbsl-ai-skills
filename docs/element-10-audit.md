# Аудит изменений 1С:Предприятие.Элемент 10.0

## Источники и границы проверки

- Changelog и профильные страницы читались из `xbsl-docs` MCP с фильтром
  `version: 10.0`; для метаданных сверялись [ProjectElements](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/ProjectElements/),
  для форм — [InterfaceComponents](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/),
  для методов и типов — [XBSL stdlib](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/).
- У `xbsl-deploy` просмотрены фактически используемые методы Console API и
  операции панели управления: сборка, релиз библиотеки, развёртывание,
  синхронизация ветки, обновление версии технологии. Для расширения маршрут
