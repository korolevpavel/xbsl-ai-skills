# Совместимость XBSL с Element 10.0

## Изменения API в 10.0

- У `Обходимое` и `Последовательность` вызов свёртки с начальным значением имеет вид `Свернуть<ТипРезультата>(НачальноеЗначение, Операция)`. Одноаргументный `Свернуть(Операция)` остаётся доступен. Старую двухаргументную перегрузку без параметра типа не используй на target 10.0. [Контракт](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Iterable_ru/).
- У `СериализацияJson.ПрочитатьОбъект` удалён параметр `Тип: Коллекция<Тип>`; для коллекции используй `ПрочитатьОбъект<Массив<ТипЭлемента>>(Источник, Настройки)` или другую конкретную коллекцию. Вызов с `Тип<T>` остаётся документированной перегрузкой и в 10.0; текущие примеры `HttpСервис` и `Структура` не требуют замены. [Контракт](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Json/JsonSerialization_ru/).
- У общего `РегистрСведений.КлючЗаписи` удалено `КлючОсновногоФильтра`. Ссылка на это свойство в конкретном ключе записи допустима только для **независимого** регистра. [Контракт](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/InformationRegisters/InformationRegister.RecordKey_ru/).

## Чтение JSON в режиме совместимости 10.0

После `ЧтениеJson.ПрочитатьСодержимое<Тип>()` для объекта или массива позиция остаётся на их последнем токене, а для литерала не сдвигается. Если код продолжает обход потока, вызови `Следующий()` явно. В режиме ниже 10.0 этот метод сам переходил на следующий токен; не добавляй дополнительный переход в коде, который должен сохранить старый режим. Методы `ПрочитатьСодержимоеКакМассив()` и `ПрочитатьСодержимоеКакСоответствие()` помечены устаревшими; для нового кода используй обобщённый метод. [Контракт](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Json/JsonReader_ru/).

```xbsl
// Фрагмент метода для target 10.0; JsonТекст содержит объект JSON.
знч Чтение = новый ЧтениеJson(JsonТекст)
Чтение.Следующий()  // позиция на начале объекта
знч Данные = Чтение.ПрочитатьСодержимое<Соответствие<Строка, Объект?>>(новый НастройкиЧтенияОбъектовJson())
Чтение.Следующий()  // перейти после последнего токена объекта перед дальнейшим обходом
```

## Список выражения `В`

В языке запросов элемент списка `В (...)` не может сам быть выражением `В`. Если в списке **больше 128** значений, разрешены только константы и параметры; для сложного большого списка используй временную таблицу. Один параметр-массив (`Поле В (%Значения)`) в текущих RLS-паттернах этому ограничению не противоречит. Для составного типа с подзапросом предпочитай `СУЩЕСТВУЕТ`. [Контракт](https://1cmycloud.com/console/help/element/10.0/docs/topics/in-expression/).
