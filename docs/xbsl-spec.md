# Компактная спецификация XBSL
Синтаксический контракт для генерации и изменения `.xbsl`-кода.
Версия платформы: **1С:Предприятие.Элемент 9.3**.
Это не справочник API платформы. Имена типов, методов и обработчиков уточняй через
`xbsl-docs`; предметные паттерны — в `references/` соответствующего скилла.
## Главное
- Ключевые слова пишутся строчными буквами: `метод`, `если`, `новый`, `возврат`.
- Составная инструкция завершается отдельной строкой с `;`.
- Обычные инструкции не оканчивай `;`.
- Нет `КонецЕсли`, `КонецЦикла`, `КонецПопытки`, `Тогда`, `Процедура` и `Функция`.
- `=` присваивает значение; для сравнения используй `==` и `!=`.
- Отсутствующее значение — `Неопределено`, не `null`, `None` или `undefined`.
- Булевы литералы: `Истина` и `Ложь`.

## Файл, импорт и аннотации
Импорт указывай в начале файла, аннотации — непосредственно перед объявлением.

```xbsl
импорт Продажи

@НаСервере @ДоступноСКлиента
статический метод ПолучитьИтог(): Число
    возврат Продажи.ПолучитьИтог()
;
```

Используй только аннотации, типы и обработчики из документации или референса скилла.

## Методы, переменные и выражения
Метод имеет имя, параметры с типами и необязательный тип результата; nullable-тип
обозначается суффиксом `?`.

```xbsl
метод Найти(Ид: Строка): Товар.Ссылка?
    знч Товар = Товары.НайтиПоИд(Ид)
    если Товар != Неопределено
        возврат Товар.Ссылка
    ;
    возврат Неопределено
;
```

- `знч` — неизменяемая переменная; `пер` — переменная, которую можно переназначить.
- `исп` открывает ресурсный контекст для объектов, требующих освобождения ресурса.
- Создание объекта: `новый Тип(Параметр = Значение)`.
- Вызов метода: `Объект.Метод(Аргумент)`; именованный аргумент: `Имя = Значение`.
- Интерполяция: `%{Выражение}` вызывает `ВСтроку()`, `${Выражение}` — `Представление()`.

## Имена переменных и констант

- Переменные и параметры нового кода — `UpperCamelCase`, без `_`, цифровых
  суффиксов и имени типа в роли имени переменной.
- Константы — `UPPER_SNAKE_CASE`.
- Булевы имена описывают истинное состояние: `Это...`, `Есть...`, `Содержит...`
  или подходящее причастие.
- Используй предметные имена без бессмысленных сокращений. Допустимы `Ид`,
  `Ндс`, `Фио`, `Мчд`, `Мсфо` и однобуквенные uppercase-параметры коротких
  небизнесовых lambda.
- Для generated/external English-контракта явно отметь исключение рядом с кодом.

Правила применяются к новому генерируемому XBSL, но не переименовывают методы,
элементы метаданных и произвольный legacy-код.

## Ветвление и циклы
Условия и циклы не используют `тогда`, `цикл` и парные ключевые слова завершения.

```xbsl
если Сумма > 0
    Обработать(Сумма)
иначе если Сумма == 0
    Сообщить("Нет данных")
иначе
    выбросить новый ИсключениеНедопустимоеСостояние("Сумма отрицательная")
;

выбор Статус
когда Новый
    Подготовить()
иначе
    Обработать()
;

для Строка из Строки
    Обработать(Строка)
;

пока ЕстьСледующаяСтраница()
    ЗагрузитьСледующуюСтраницу()
;
```

`возврат` завершает метод. Для раннего выхода из цикла используй `прервать`.

## Ошибки
Перехватывай исключения через `попытка` / `поймать`; блок закрывается отдельным `;`.

```xbsl
метод ПрочитатьДанные(): Строка
    попытка
        возврат Хранилище.Прочитать()
    поймать Ошибка: Исключение
        выбросить новый ИсключениеНедопустимоеСостояние(Ошибка.Описание)
    вконце
        ОсвободитьРесурсы()
    ;
;
```

`исключение` объявляет собственный тип исключения; для перехвата используй `поймать`.

## Коллекции
Используй типизированные коллекции, когда тип известен; для изменяемых — их методы.

```xbsl
знч Числа: Массив<Число> = []
Числа.Добавить(10)

пер Товары: Соответствие<Строка, Число> = {:}
Товары.Вставить("Артикул", 10)

если Товары.СодержитКлюч("Артикул")
    знч Количество = Товары.Получить("Артикул")
;
```

- Массив: `[]`, `<Тип>[]`, `Добавить()`, обход через `для Элемент из Массив`.
- Соответствие: `{Ключ: Значение}` или `{:}`, `Вставить()`, `Получить()` и
  `ПолучитьИлиНеопределено()`.
- Доступ по индексу допустим, но чтение отсутствующего ключа вызывает исключение.

## Перед записью
1. Прочитай профильный референс скилла и этот файл.
2. Сверь через `xbsl-docs` все API-вызовы, типы, аннотации и сигнатуры обработчиков.
3. Проверь каждый составной блок: открыт ключевым словом, закрыт одной строкой `;`.
4. Не переноси синтаксис из 1С:Предприятия 8, Python, JavaScript или SQL.
