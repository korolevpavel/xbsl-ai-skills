# Недопустимые символы в именах файлов (target 10.0+)

`ОбъектноеХранилище.Загрузить()` проверяет имя файла на символы, запрещённые хотя бы одной поддерживаемой ОС (в частности `?`). Выгрузка через `ВыгрузкаФайлов.НачатьВыгрузку()` тоже учитывает режим. Режим и строка замены задаются **для всего приложения**, а не для одного `СписокФайлов` или фотографии. По умолчанию действует `ИсправлятьПриЗагрузке`, замена — пустая строка (недопустимые символы удаляются).

| Режим | `log.txt` | `log?.txt` при загрузке | Имя при выгрузке `log?.txt` |
| --- | --- | --- | --- |
| `НеИсправлять` | сохраняется и выгружается без изменений | `ИсключениеНедопустимыйАргумент`; объект не загружен | если такое имя уже хранится, выгрузка с недопустимым именем вызывает исключение |
| `ИсправлятьПриЗагрузке` | без изменений | хранится как `log.txt` (или `log_.txt` при замене `_`) | уже исправленное имя выгружается без изменений |
| `ИсправлятьПриВыгрузке` | без изменений | в хранилище остаётся `log?.txt` | скачивается как `log.txt` (или `log_.txt` при замене `_`) |

Если выбран `НеИсправлять`, обработай `ИсключениеНедопустимыйАргумент` в сценарии загрузки/выгрузки и сообщи пользователю, что имя файла надо изменить. Например, для явной загрузки в хранилище:

```xbsl
попытка
    возврат ОбъектноеХранилище.Загрузить(ИмяФайла, Данные).Ссылка
поймать Ошибка: ИсключениеНедопустимыйАргумент
    выбросить новый ИсключениеНедопустимыйАргумент("Недопустимое имя файла. Переименуйте файл и повторите загрузку.", Ошибка)
;
```

Если пользователь просит изменить политику приложения, настрой её один раз на сервере в согласованной точке инициализации приложения, **не** внутри обработчика формы или загрузки отдельного файла:

```xbsl
ОбъектноеХранилище.УстановитьАвтоматическоеИсправлениеИмениФайла(
    РежимИсправленияИмениФайлаДвоичногоОбъекта.ИсправлятьПриВыгрузке, "_")
```

Текущие значения можно прочитать через `ПолучитьРежимАвтоматическогоИсправленияИмениФайла()` и `ПолучитьЗаменуНедопустимыхСимволовВИмениФайла()`. На target ниже 10.0 не генерируй новые вызовы без проверки его API.
