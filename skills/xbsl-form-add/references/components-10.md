# Компоненты интерфейса Element 10.0

Используй примеры только при целевой версии **10.0 или выше** и явной потребности в компоненте. Фрагменты ниже вставляются в `Содержимое` формы или группы; `Тип` параметризуй существующими типами проекта. Для `ФормаОбъекта` используй `=Объект.<Реквизит>`, для независимой формы — объявленное свойство или метод. Не оставляй ссылки на несуществующие объекты, реквизиты и обработчики.

## Панель тегов

`СписокЗначений` должен давать массив элементов указанного типа. Для перечисления можно использовать `Элементы()`; для массива ссылок формы объекта — реквизит объекта. Обработчик `ПриНажатииНаТег` добавляй только если теги должны реагировать на нажатие.

```yaml
-
    Тип: ПанельТегов<Навыки.Ссылка>
    Имя: ПанельНавыков
    Заголовок: Навыки
    СписокЗначений: =Объект.Навыки
```

[Схема](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/TagsPanel_ru/) · [пример](https://1cmycloud.com/console/help/element/10.0/docs/topics/tag-panel/).

## Панель этапов

Для перечисления элементы этапов формируются автоматически. `ТекущийЭтап` привяжи к реквизиту перечисления того же типа. `Этапы` заполняй явно, если порядок и состав отличаются от перечисления.

```yaml
-
    Тип: ПанельЭтапов<СтатусЗаказа>
    Имя: ЭтапыЗаказа
    ТекущийЭтап: =Объект.Статус
```

Горизонтальная панель с невместившимися этапами показывает кнопку на широком экране и горизонтальную прокрутку на мобильном. [Схема](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/StagesPanel_ru/) · [пример](https://1cmycloud.com/console/help/element/10.0/docs/topics/stages-panel/).

## Канбан-доска

Размещай в форме с достаточной шириной; родительскому шаблону задай растягивание и `ШиринаВКолонках: Неограниченная`, как в официальном примере. Ниже `Задачи` — существующий документ с полями `Наименование` и `Статус`, а `СтатусыЗадач` — существующий справочник. Тип строки повторяется в `Источник` и `Карточка`; `ЗначениеКолонки` возвращает тот же тип, что и второй параметр доски. Для каждого значения статуса назначь колонку: одних заголовков недостаточно для распределения карточек.

```yaml
Тип: ПроизвольныйШаблонФормы
РастягиватьПоВертикали: Истина
РастягиватьПоГоризонтали: Истина
ШиринаВКолонках: Неограниченная
Содержимое:
    Тип: КанбанДоска<ДинамическийСписок<ФормаДоскиЗадач.ДанныеСтрокиДоски>, СтатусыЗадач.Ссылка?, Строка?>
    Имя: ДоскаЗадач
    ЗначениеКолонки: =ДанныеСтроки.Данные.Статус
    Источник:
        Тип: ДинамическийСписок<ФормаДоскиЗадач.ДанныеСтрокиДоски>
        ИмяТипаДанныхСтроки: ДанныеСтрокиДоски
        ОсновнаяТаблица:
            Таблица: Задачи
            Поля:
                - Тип: ПолеДинамическогоСписка
                  Выражение: Наименование
                - Тип: ПолеДинамическогоСписка
                  Выражение: Статус
    Карточка:
        Тип: СтандартнаяКанбанКарточка<СтрокаДинамическогоСписка<ФормаДоскиЗадач.ДанныеСтрокиДоски>>
        Заголовок: =ДанныеСтроки.Данные.Наименование
    Колонки:
        - Заголовок: Новые
        - Заголовок: Завершённые
```

Если статусы — ссылки на справочник, после получения ссылок на сервере установи значения колонок в `ПослеСоздания`:

```xbsl
@Обработчик
метод ПослеСоздания()
    знч Статусы = ПолучитьСтатусыЗадач()
    Компоненты.ДоскаЗадач.Колонки[0].Значения = [Статусы["Новая"]]
    Компоненты.ДоскаЗадач.Колонки[1].Значения = [Статусы["Завершена"]]
;
```

`ПолучитьСтатусыЗадач()` реализуй как запрос к реальному справочнику с результатом `Соответствие<Строка, СтатусыЗадач.Ссылка>` по уникальному коду или другому устойчивому ключу; см. [официальный пример](https://1cmycloud.com/console/help/element/10.0/docs/topics/kanban-board/). Для свимлайнов дополнительно укажи `ЗначениеСвимлайна` и `Свимлайны`. Если сценарий требует перенос карточек, добавь обработчик `ПриОкончанииПеретаскивания` и сохранение нового статуса; само перетаскивание не обновляет запись. [Схема](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/KanbanBoard_ru/).

## Географическая карта

Создай структуру `ДанныеМаркера` с полем `Ид: Число` (с собственным UUID) или замени тип параметра на существующую структуру данных маркера:

```yaml
ВидЭлемента: Структура
Ид: <UUID>
Имя: ДанныеМаркера
ОбластьВидимости: ВПодсистеме
Окружение: КлиентИСервер
Поля:
    - Имя: Ид
      Тип: Число
```

Маркеры и координаты центра должны соответствовать координатам объектов. `НастройкиБазовогоСлоя` задавай для выбранного тайлового сервера; URL ниже — пример из документации, перед использованием проверь условия провайдера и доступность сети у клиента.

```yaml
-
    Тип: ГеографическаяКарта<ДанныеМаркера?>
    Имя: КартаФилиалов
    РастягиватьПоГоризонтали: Истина
    РастягиватьПоВертикали: Истина
    КоординатыЦентра:
        Тип: ГеографическиеКоординаты
        Долгота: 37.61556
        Широта: 55.55222
    Масштаб: 8
    Маркеры:
        - Заголовок: Филиал
          Координаты:
              Долгота: 37.607
              Широта: 55.8387
          Данные:
              Тип: ДанныеМаркера
              Ид: 1
    НастройкиБазовогоСлоя:
        Тип: НастройкиТайловогоСервераГеографическойКарты
        Поставщик: OpenStreetMap
        ШаблонUrl: https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

Для динамических данных вместо статического списка маркеров задай `Маркеры: =ПолучитьМаркеры()` и реализуй метод, возвращающий маркеры с тем же типом `Данные`. Карта и тип `ГеографическаяКарта` доступны с 10.0. [Схема](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/GeographicMap_ru/) · [пример](https://1cmycloud.com/console/help/element/10.0/docs/topics/geographic-map/).

## Мобильный интерфейс

Для всех четырёх компонентов события `ПриНаведении` и `ПриПотереНаведения` не поддерживаются на мобильных устройствах. Не делай их единственным способом открыть данные или выполнить действие. Для канбана и карты проверь рабочую ширину и сценарии касания в целевом клиенте. [Схемы компонентов](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/).
