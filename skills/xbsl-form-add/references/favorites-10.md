# Избранное в формах (target 10.0+)

Добавляй `ВажностьИзбранногоПользователя` только если пользователь просит изменить видимость или расположение команды «Избранное». Свойство принадлежит форме, то есть `Наследует` у `КомпонентИнтерфейса` с типом `Форма`, `ФормаОбъекта`, `ФормаСписка` или `ФормаОтчета`:

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: <UUID>
Имя: ТоварыФормаСписка
Наследует:
    Тип: ФормаСписка
    ВажностьИзбранногоПользователя: Высокая
```

Допустимы `Отсутствует`, `Обычная`, `Высокая`; отсутствие свойства сохраняет выбор следующего уровня. Для формы сущности или списка приоритет: **форма → сущность → клиентское приложение**. Для самостоятельной формы: **форма → клиентское приложение**. Берётся первое заданное значение; если его нет нигде, действует `Обычная`.

`Отсутствует` скрывает команду, `Обычная` ставит её среди дополнительных команд и показывает индикатор у заголовка, `Высокая` выводит команду рядом с заголовком (в мобильном клиенте — первой среди дополнительных). Приложение без аутентификации не показывает «Избранное» при любом значении. На target ниже 10.0 свойство не генерируй.

Настройки сущности описаны в `../../xbsl-meta-add/references/Справочник.md` и соответствующих object reference; настройка стандартного клиентского приложения — в `../../xbsl-form-dashboard/references/регистрация.md`.
