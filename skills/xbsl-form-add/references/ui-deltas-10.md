# Дополнительные UI-контракты Element 10.0

Читай только при запросе соответствующего компонента. На более старом target
эти свойства и вложенные узлы не добавляй.

## Заголовок обсуждения

У `КомпонентОбсуждения` доступно опциональное
`ОтображатьЗаголовок: ВычисляемоеВыражение|Авто|Булево`. Добавляй только при
явном требовании показать или скрыть стандартный заголовок:

```yaml
Тип: КомпонентОбсуждения
Имя: ОбсуждениеЗаказа
ОтображатьЗаголовок: Ложь
```

`Авто` оставляет выбор платформе. Это свойство не заменяет настройку контекста
обсуждения или регистрацию приложения в системе взаимодействия.
[Схема компонента](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/ConversationComponent_ru/).

## Текущий раздел формы

Для `ШаблонФормыСРазделами` тип 10.0 предоставляет:

- `ТекущаяГруппаРаздела: Группа` — доступна только для чтения;
- `УстановитьТекущуюГруппуРаздела(Раздел: РазделФормы|Группа): Булево` —
  возвращает `Ложь`, если раздел не входит в форму или скрыт;
- `ПриСменеГруппыРаздела` — событие после выбора раздела пользователем,
  обработчик получает `СобытиеСДанными<Группа>`.

В существующей форме с `Содержимое.Тип: ШаблонФормыСРазделами` можно задать
обработчик на самом шаблоне:

```yaml
Содержимое:
    Тип: ШаблонФормыСРазделами
    ПриСменеГруппыРаздела: ПриСменеГруппыРаздела
    ОсновнойРаздел:
        Тип: Группа
        Имя: ОсновнойРаздел
        Заголовок: Основное
```

```xbsl
метод ПриСменеГруппыРаздела(Источник: ШаблонФормыСРазделами,
                           Событие: СобытиеСДанными<Группа>)
    // Событие.Данные — выбранная группа.
;
```

Вызов `УстановитьТекущуюГруппуРаздела()` делай только с существующей видимой
группой или разделом этой формы и проверяй возвращаемое значение. Не пытайся
присваивать `ТекущаяГруппаРаздела` напрямую. Не добавляй обработчик без
пользовательского сценария управления разделами.
[Схема типа](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Interface/Forms/FormWithSectionsTemplate_ru/).

## Стандартная обработка события

У `СобытиеСДанными<ТипДанных>` в 10.0 доступно изменяемое свойство
`СтандартнаяОбработка: Булево`. Если обработчик явно должен отменить
предопределённую обработку платформы, можно установить его в `Ложь`.
Отмена стандартной обработки не отменяет уже произошедшее действие. В обычных
обработчиках оставляй свойство без изменений.
[Схема события](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Interface/EventWithData_ru/).

## Встроенные веб-страницы клиентского приложения

Эти свойства относятся к `СтандартноеКлиентскоеПриложениеСРазделами` в
`Приложение.yaml`, а не к обычной `ФормаОбъекта`. У
`ВстроенныеВебСтраницы` дочернее поле `ВебСтраницы` содержит массив описаний
встроенных веб-страниц. У `ИнтерфейсВстроенныхВебСтраниц` доступны новые
вложенные узлы:

| Узел | Тип по схеме 10.0 |
| --- | --- |
| `КомандыПанели` | `ФрагментКомандногоИнтерфейса?` |
| `КомпонентМеню` | `ВсплывающийКомпонент?` |
| `ОсновнаяКомандаМеню` | `Команда?` |
| `ДополнительныеКомандыМеню` | `ФрагментКомандногоИнтерфейса?` |

Минимальная подтверждённая часть описания страницы:

```yaml
Наследует:
    Тип: СтандартноеКлиентскоеПриложениеСРазделами
    ВстроенныеВебСтраницы:
        ВебСтраницы:
            -
                Тип: ПроизвольнаяВстроеннаяВебСтраница
                Url: https://example.com/
                Ид: ВнешняяСтраница
                Представление: Внешняя страница
```

Для настройки панели добавляй `ИнтерфейсВстроенныхВебСтраниц` рядом с
`ВстроенныеВебСтраницы` и только нужные вложенные узлы. Например, список
команд панели имеет такую структуру:

```yaml
ИнтерфейсВстроенныхВебСтраниц:
    КомандыПанели:
        Тип: ФрагментКомандногоИнтерфейса
        Элементы:
            - =<СуществующаяКоманда>
```

`<СуществующаяКоманда>` нужно заменить разрешаемой ссылкой из проекта. Для
`КомпонентМеню` и `ОсновнаяКомандаМеню` не создавай произвольную реализацию
без конкретного компонента или команды. Если их нет, оставь стандартный UI
платформы и сообщи, что кастомное меню требует отдельного описания.
`Имя` для команды или группы задавай только внутри самостоятельного элемента
проекта вида `ФрагментКомандногоИнтерфейса`. Во встроенном фрагменте компонента,
например в `ИнтерфейсВстроенныхВебСтраниц.КомандыПанели`, у описанной на месте
`НавигационнаяКоманда` поле `Имя` не указывай: компилятор Element `10.0.2-19`
его отклоняет. Ссылка `=<СуществующаяКоманда>` остаётся предпочтительной,
если команда уже определена в проекте.

[Схема приложения](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/StandardClientApplicationWithSections/),
[схема интерфейса веб-страниц](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/InterfaceComponents/Std/InterfaceComponents/StandardClientApplicationWithSections/EmbeddedWebPagesInterface/EmbeddedWebPagesInterfaceInstance_ru/),
[пример страницы](https://1cmycloud.com/console/help/element/10.0/docs/topics/app-integration/).
