# Спецификация: ФормаОтчета

## Структура (target 10.0+)

```yaml
ВидЭлемента: КомпонентИнтерфейса
Ид: <UUID>
Имя: <ИмяОтчета>ФормаОтчета
ОбластьВидимости: ВПодсистеме
Наследует:
    Тип: ФормаОтчета<<ИмяОтчета>>
    ВключатьВАвтоИнтерфейс: Ложь
    Отчет:
        Тип: <ИмяОтчета>
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: Группа
            Компоновка: Вертикальная
            Содержимое:
                # --- Параметры (если report_params не пуст) ---
                -
                    Тип: Группа
                    Содержимое:
                        -
                            Тип: ПолеВвода<<Тип>>
                            Заголовок: <Представление параметра>
                            Значение: =Отчет.Параметры.<ИмяПараметра>
                # --- Просмотр отчёта (всегда) ---
                -
                    Тип: ПросмотрОтчета<<ИмяОтчета>>
                    Имя: ПросмотрОтчета
                    Отчет: =Отчет
                    РастягиватьПоВертикали: Истина
                    РастягиватьПоГоризонтали: Истина
                    ТолькоЧтение: Истина
```

## Вариант без параметров (report_params пуст)

Если `report_params` пуст — убираем внешнюю `Группа` с `Компоновка: Вертикальная` и секцию параметров, оставляем только `ПросмотрОтчета`:

```yaml
    Содержимое:
        Тип: ПроизвольныйШаблонФормы
        Содержимое:
            Тип: ПросмотрОтчета<<ИмяОтчета>>
            Имя: ПросмотрОтчета
            Отчет: =Отчет
            РастягиватьПоВертикали: Истина
            РастягиватьПоГоризонтали: Истина
            ТолькоЧтение: Истина
```

## Правила

- `ВключатьВАвтоИнтерфейс: Ложь` — **всегда**
- В 10.0 `Отчет` — системное свойство типизированной формы. Задай `Наследует.Отчет.Тип: <ИмяОтчета>`; отдельное `Свойства[].Отчет` не создавай.
- `Заголовок` можно не указывать: платформа использует `=Отчет.Представление`. Явное значение добавляй только если нужен другой текст.
- Параметры — отображаются через `=Отчет.Параметры.<ИмяПараметра>`. Тип ПолеВвода подбирается по типу параметра:
  - `ДатаВремя` → `ПолеВвода<ДатаВремя>`
  - `Дата?` → `ПолеВвода<Дата?>`
  - `<Справочник>.Ссылка?` → `ПолеВвода<<Справочник>.Ссылка?>`
  - `Число` → `ПолеВвода<Число>`
  - `Строка` → `ПолеВвода<Строка>`
- Для ссылочных параметров поле `Заголовок` обязательно
- Если `report_params` содержит `required: true` из
  `Макет.Параметры[].Обязательный`, покажи поле пользователю: отчёт не
  построится до ввода значения. Обязательность проверяет отчёт; отдельное
  свойство `Обязательный` у `ПолеВвода` здесь не добавляй.
- `ТолькоЧтение: Истина` на ПросмотрОтчета — **всегда** (отчёты только для просмотра)
- `ПросмотрОтчета<<ИмяОтчета>>` получает `Отчет: =Отчет`; тип отчёта известен без ручного `как <ИмяОтчета>` в XBSL.

Если обработчик формы меняет параметр, используй типизированное свойство напрямую:

```xbsl
Компоненты.ПросмотрОтчета.Отчет.Параметры.<ИмяПараметра> = НовоеЗначение
Компоненты.ПросмотрОтчета.Обновить()
```

## Совместимость до 10.0

Для target 9.0 и ниже используй прежние нетипизированные `ФормаОтчета` и `ПросмотрОтчета`, явный `Заголовок: =Отчет.Представление` и пользовательское `Свойства[].Отчет` с `Тип` и `ЗначениеПоУмолчанию`. Системное `Наследует.Отчет` там отсутствует. Не смешивай эти два контракта в одной форме.

[Типизация в 10.0](https://1cmycloud.com/console/help/element/10.0/docs/topics/whats-new-in-10-0/#типизация-компонентов-формаотчета-и-просмотротчета) · [форма с параметрами](https://1cmycloud.com/console/help/element/10.0/docs/topics/use-query-to-create-report/) · [форма без параметров](https://1cmycloud.com/console/help/element/10.0/docs/topics/display-reports-in-user-interface/).

## Обновление объекта Отчет после создания формы (Шаг 6)

Для объекта типа `Отчет` свойства располагаются внутри секции `Интерфейс`, но
без подсекций `Объект`/`Список`:

```yaml
Интерфейс:
    ВключатьВАвтоИнтерфейс: Истина
    Форма: <ИмяОтчета>ФормаОтчета
```

Секция добавляется **после `ОбластьВидимости`**, до `ВидИсточникаДанных` /
`ПараметрыЗапроса`. Если `Интерфейс` уже существует, объедини свойства и не
перезаписывай секцию. `Форма` проверяй и добавляй независимо от
`ВключатьВАвтоИнтерфейс`; без пользовательской формы это свойство не требуется.
