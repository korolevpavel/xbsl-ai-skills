# Избранное у сущностей (target 10.0+)

У `Справочник`, `Документ`, `ХранилищеНастроек` и `ПланОбмена` свойство `ВажностьИзбранногоПользователя` задаётся на верхнем уровне YAML объекта. Добавляй его только по прямому запросу. Возможные значения: `Отсутствует`, `Обычная`, `Высокая`.

```yaml
ВидЭлемента: Справочник
Ид: <UUID>
Имя: Товары
ОбластьВидимости: ВПодсистеме
ВажностьИзбранногоПользователя: Высокая
```

Для формы сущности и её списка приоритет: **форма → сущность → клиентское приложение**. Самостоятельная форма проверяет только **форму → клиентское приложение**. Берётся первое заданное значение; если все уровни пусты, используется `Обычная`. `Отсутствует` скрывает команду «Избранное», `Обычная` показывает её как дополнительную, `Высокая` — рядом с заголовком формы. В приложении без аутентификации команда и иконка «Избранного» скрыты независимо от настроек. На target ниже 10.0 свойство не генерируй.

Форма настраивается через `../../xbsl-form-add/references/favorites-10.md`; стандартное клиентское приложение — через `../../xbsl-form-dashboard/references/регистрация.md`.

Источники: [Избранное и приоритет](https://1cmycloud.com/console/help/element/10.0/docs/topics/favorites/), [схема справочника](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/ProjectElements/Std/ProjectElements/Catalog/), [значения](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/Interface/Favorites/UserFavoritesImportance_ru/).
