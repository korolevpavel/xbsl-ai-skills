# Спецификация: Обработка

## Назначение

Факты платформы:

- `ВидЭлемента: Обработка` описывает исполняемый объект с операциями.
- Для операции нужен одноименный обработчик в XBSL-модуле.

Соглашения генератора:

- Имя задавай PascalCase, существительное или действие по смыслу обработки.
- Минимальный комплект содержит одну операцию и одноименный метод.

## Версия

- Минимальная версия платформы: 9.1+.
- `КонтрольДоступа` обработки и операций доступен с 10.0.

## YAML

Required:

```yaml
ВидЭлемента: Обработка
Ид: <UUID>
Имя: <Имя>
ОбластьВидимости: ВПодсистеме
Операции:
    -
        Имя: <ИмяОперации>
        Представление: <Представление>
```

Negative:

- Не объявляй операцию без одноименного метода.
- Не добавляй форму как обязательное свойство минимального комплекта.

### Права вызова (10.0+)

`КонтрольДоступа` обработки задаёт общее право вызова. Собственный
`КонтрольДоступа` операции имеет приоритет: если он задан, права обработки
для этой операции не проверяются. Если обе секции отсутствуют, действует
платформенное значение по умолчанию `РазрешеноАдминистраторам`.

```yaml
ВидЭлемента: Обработка
Ид: <UUID>
Имя: РасчетНалогов
ОбластьВидимости: ВПодсистеме
КонтрольДоступа:
    Разрешения:
        ПоУмолчанию: РазрешеноАутентифицированным
Операции:
    -
        Имя: Рассчитать
        КонтрольДоступа:
            Разрешения:
                Вызов: РазрешеноАдминистраторам
    -
        Имя: ПересчитатьПоПравилам
        КонтрольДоступа:
            Разрешения:
                Вызов: РазрешенияВычисляются
            Обработчик: ВычислитьКлючиПересчета
```

Для операции с `РазрешенияВычисляются` укажи имя существующего метода
расчёта ключей доступа в модуле обработки. Для расчёта на уровне всей
обработки используй `РазрешенияВычисляются` в общем `ПоУмолчанию` или
`Вызов` и обработчик `ВычислитьРазрешенияДоступа()` в модуле обработки;
у верхнеуровневого `КонтрольДоступа` нет свойства `Обработчик`.
Не добавляй права `Чтение`, `Запись` и другие права объектов данных:
для обработки документировано право `Вызов`.

При переименовании операции с собственным `КонтрольДоступа` в обработчике
обновления проекта вызови `РасчетНалогов.ПересчитатьРазрешенияДоступа()`:
рассчитанные разрешения хранятся с именем операции. Перед переименованием
проверь это вручную: одно только текущее YAML не содержит прежнего имени.

В модуле проекта добавь обработчик обновления с уникальными `Ид` и `Номер`:

```xbsl
@ОбновлениеПроекта(Ид="ПересчетПравРасчетНалогов", Номер=3)
метод ПересчитатьПраваПослеПереименования()
    РасчетНалогов.ПересчитатьРазрешенияДоступа()
;
```

[свойства обработки](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/ProjectElements/Std/ProjectElements/Processing/),

## UUID

Required:

- UUID получает объект обработки.
- Подтвержденная минимальная запись `Операции[]` не требует собственного UUID.

Negative:

- Не добавляй UUID операции без явного правила в контракте объекта.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.
- Импорты нужны только при обращении к объектам внешних подсистем из YAML или модуля.

Negative:

- Не расширяй видимость обработки только из-за наличия операции.

## Companion artifacts

Required:

- `*.yaml` - описание объекта.
- `*.Объект.xbsl` - обязательный модуль объекта с обработчиками операций.

Negative:

- Отсутствующий модуль или метод с другим именем не закрывает контракт операции.

## Генерация

Required:

- Skill создает `<Имя>.yaml` и `<Имя>.xbsl`.
- Для каждой операции генерируется метод с `@Обработчик`.

Negative:

- Повторный запуск не должен дублировать уже существующий обработчик.

## Валидация

Required:

- `set(Операции[].Имя)` является подмножеством методов с `@Обработчик`.
- Модуль находится рядом с YAML и называется `<Имя>.Объект.xbsl`.

Negative:

- `missing_handler`, `wrong_handler_name`.
