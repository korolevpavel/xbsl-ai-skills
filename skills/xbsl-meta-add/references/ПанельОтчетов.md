# Спецификация: ПанельОтчетов

## Назначение

Platform facts:

- `ВидЭлемента: ПанельОтчетов` описывает панель, на которой дизайнер
  «1С:Аналитики» размещает отчеты.
- `Представление` является обязательным полем.
- `Макет` формируется автоматически в дизайнере и является designer-owned.
- Если `Форма` не указана, используется автоматически сгенерированная форма.

Local conventions:

- Минимальная генерация не создает manual designer-owned layout.
- Не добавляй прямую YAML-ссылку панели на объект `Отчет`, если такого поля
  нет в контракте объекта.

## Версия

- Минимальная версия платформы: 9.1+.

## YAML

Required:

```yaml
ВидЭлемента: ПанельОтчетов
Ид: <UUID>
Имя: <ИмяПанели>
ОбластьВидимости: ВПодсистеме
Представление: <Название панели>
```

Optional:

- `ВключатьВАвтоИнтерфейс` имеет default `Истина`.
- `Описание` имеет default пустая строка.
- `Изображение` задает картинку команды открытия.
- `Форма` может указывать форму, наследующую `ФормаОтчета`.

Negative:

- Не добавляй `Макет` вручную в минимальный YAML.
- Не добавляй выдуманное поле прямой связи с `Отчет`.

## UUID

Required:

- UUID получает объект `ПанельОтчетов`.

Negative:

- Designer-owned элементы `Макет` не получают UUID в минимальном YAML.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно.
- `Импорт` указывай только при фактических ссылках на внешний namespace.

Negative:

- Не добавляй `Импорт` для пустой минимальной панели.

## Companion artifacts

Required:

- `*.yaml` - описание панели отчетов.

Negative:

- Форма не является обязательным companion.
- XBSL-модуль не является обязательным companion.
- Designer-owned `Макет` не создается вручную.

## Генерация

Required:

- Skill создает `<Имя>.yaml` с обязательным `Представление`.
- Форму добавляй только по явному запросу пользователя.

Local conventions:

- Для минимального комплекта достаточно YAML без manual layout.

Negative:

- Повторный запуск не должен добавлять пустой `Макет`.

## Валидация

Required:

- `Представление` присутствует и непустое.
- Минимальный YAML не содержит `Макет`.

Negative:

- `missing_presentation`.
