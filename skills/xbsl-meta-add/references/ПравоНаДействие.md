# Спецификация: ПравоНаДействие

## Назначение

Platform facts:

- `ВидЭлемента: ПравоНаДействие` описывает самостоятельный объект права на действие.
- `Параметры[]` описывают параметры права; каждый параметр содержит `Ид`,
  `Имя` и `Тип`.
- `Импорт` подключает пространства имен, а `ОбластьВидимости` по умолчанию
  равна `ВПодсистеме`.

Local conventions:

- Минимальная генерация не меняет пользователей, роли или настройки контроля
  доступа.
- Если нужны прикладные разрешения, используй отдельный workflow контроля
  доступа, не копируя его правила в этот object reference.

## Версия

- Минимальная версия платформы: 9.1+.

## YAML

Required:

```yaml
ВидЭлемента: ПравоНаДействие
Ид: <UUID>
Имя: <ИмяПрава>
ОбластьВидимости: ВПодсистеме
```

Optional:

```yaml
Импорт:
    - <ИмяПодсистемы>
Параметры:
    -
        Ид: <UUID>
        Имя: <ИмяПараметра>
        Тип: <Тип>
```

Negative:

- Не добавляй `Элементы`: это поле относится к `ПравоНаЭлемент`.
- Не подменяй право на действие объектом `КлючДоступа` или секцией
  `КонтрольДоступа`.

## UUID

Required:

- UUID получает сам объект `ПравоНаДействие`.
- Каждый элемент `Параметры[]` получает собственный UUID.

Negative:

- Не принимай UUID для выдуманных вложенных коллекций.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно; default платформы: `ВПодсистеме`.
- `Импорт` указывай только при фактических ссылках на внешние пространства имен.

Negative:

- Не добавляй `Импорт` для локальных типов.

## Companion artifacts

Required:

- `*.yaml` - описание права на действие.

Negative:

- `.xbsl` не является обязательным companion: тематический источник описывает
  только YAML-свойства элемента.

## Генерация

Required:

- Skill создает `<Имя>.yaml` с `ВидЭлемента`, `Ид`, `Имя` и явной
  `ОбластьВидимости`.
- `Параметры[]` добавляй только когда пользователь просит параметризованное
  право.

Local conventions:

- Для общего права без параметров достаточно минимального YAML.

Negative:

- Повторный запуск не должен добавлять пустые `Параметры`.

## Валидация

Required:

- `ВидЭлемента` равен `ПравоНаДействие`.
- Каждый параметр содержит `Ид`, `Имя` и `Тип`.

Negative:

- `element_actions_are_not_action_parameters`.
