# Спецификация: ПравоНаЭлемент

## Назначение

Platform facts:

- `ВидЭлемента: ПравоНаЭлемент` описывает самостоятельный объект права на
  действия над конкретным элементом проекта или его объектами.
- `Элементы[]` содержит действия; каждый элемент содержит `Имя` и `Ид`.
- `Импорт` подключает пространства имен, а `ОбластьВидимости` по умолчанию
  равна `ВПодсистеме`.

Local conventions:

- Минимальная генерация не создает роли, пользователей или реальные
  назначения прав.
- `КлючДоступа` и прикладная секция контроля доступа остаются отдельными
  объектами и workflows.

## Версия

- Минимальная версия платформы: 9.1+.

## YAML

Required:

```yaml
ВидЭлемента: ПравоНаЭлемент
Ид: <UUID>
Имя: <ИмяПрава>
ОбластьВидимости: ВПодсистеме
Элементы:
    -
        Имя: <ИмяДействия>
        Ид: <UUID>
```

Optional:

```yaml
Импорт:
    - <ИмяПодсистемы>
```

Negative:

- Не добавляй `Параметры`: это поле относится к `ПравоНаДействие`.
- Не переносите сюда схему `КлючДоступа` или правила прикладного контроля
  доступа.

## UUID

Required:

- UUID получает сам объект `ПравоНаЭлемент`.
- Каждый элемент `Элементы[]` получает собственный UUID.

Negative:

- Элементы без `Ид` не закрывают контракт.

## Imports и visibility

Required:

- `ОбластьВидимости` задавай явно; default платформы: `ВПодсистеме`.
- `Импорт` нужен только для ссылок на внешние пространства имен.

Negative:

- Не добавляй `Импорт` для пустого минимального объекта.

## Companion artifacts

Required:

- `*.yaml` - описание права на элемент.

Negative:

- `.xbsl` не является обязательным companion: тематический источник описывает
  только YAML-свойства элемента.

## Генерация

Required:

- Skill создает `<Имя>.yaml`.
- Для каждого действия из запроса добавляй элемент в `Элементы[]` с отдельным
  UUID.

Local conventions:

- Имена действий задавай короткими существительными: `Закрытие`,
  `ИзменениеОтветственного`.

Negative:

- Не создавай production-роли и назначения прав.

## Валидация

Required:

- `ВидЭлемента` равен `ПравоНаЭлемент`.
- `Элементы[]` непустой список с `Имя` и `Ид`.

Negative:

- `action_parameters_are_not_element_actions`.
