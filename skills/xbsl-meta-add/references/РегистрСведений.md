# Спецификация: РегистрСведений

## Дефолты

- **Имя** — PascalCase, существительное во множественном числе (`КурсыВалют`, `ЦеныНоменклатуры`)
- **Видимость** — `ВПодсистеме`
- **Периодичность** — `Непериодический` (если не нужна история по времени)
- **РежимЗаписи** — `Независимый` по умолчанию; `ПодчинениеРегистратору` доступно с 10.0
- `Ведущее` — `Истина` по умолчанию у измерений независимого регистра

## UUID

Нужны: 1 (объект) + по 1 на каждое Измерение + по 1 на каждый Ресурс + по 1 на каждый пользовательский Реквизит. Стандартный `Регистратор` подчинённого регистра не получает `Ид`.

## Структура YAML

### Минимальная:

```yaml

Имя: <ИмяРегистра>
ОбластьВидимости: ВПодсистеме

Измерения:
    - Ид: <UUID>
      Имя: <ИмяИзмерения>
      Тип: <Справочник>.Ссылка?
      Ведущее: Истина
    - Ид: <UUID>
      Имя: <ИмяИзмеренияБезКаскада>
      Тип: <ДругойСправочник>.Ссылка?
      Ведущее: Ложь

    - Ид: <UUID>
      Имя: <ИмяРесурса>
      Тип: Число
      ДлинаЦелойЧасти: 15

```

## Подчинённый регистр сведений (10.0+)

Если запись должна подтверждаться документом, используй отдельный режим и
стандартный реквизит `Регистратор`. Тип регистратора включает ссылку на
существующий **Документ** и `Неопределено` (`?`). Не добавляй этому реквизиту `Ид`.

```yaml
ВидЭлемента: РегистрСведений
Ид: <UUID>
Имя: ЦеныТоваров
ОбластьВидимости: ВПодсистеме
Периодичность: День
РежимЗаписи: ПодчинениеРегистратору
ХранитьСледующийПериод: Истина
Измерения:
    -
        Ид: <UUID>
        Имя: Товар
        Тип: СправочникТовары.Ссылка?
Реквизиты:
    -
        Имя: Регистратор
        Тип: ДокументИзменениеЦен.Ссылка?
Ресурсы:
    -
        Ид: <UUID>
        Имя: Цена
        Тип: Число
```

- `РежимЗаписи: Независимый` можно не указывать: это default. Для независимого
  регистра сохраняй обычные `Ведущее` и фильтр по измерениям.
- `ХранитьСледующийПериод` существует только при периодичности, отличной от
  `Непериодический`; свойство доступно и независимому периодическому регистру.
- У подчинённого регистра в `Измерения[]` не задавай `Ведущее` и
  `ИспользоватьВОсновномФильтре`; не задавай
  `ИспользоватьПериодВОсновномФильтре` на самом регистре.
- `Активность`, `НомерСтроки`, `Индекс` — системные поля подчинённой записи,
  поэтому не называй ими измерения, ресурсы и пользовательские реквизиты.
- В подчинённом регистре нет формы записи и методов записи отдельной записи.
  Записывай через `НаборЗаписей`; его фильтр содержит только `Регистратор`.
- При изменении режима подчинённости существующего регистра платформа требует
  отсутствия движений. Удаление типа документа из состава `Регистратор` удаляет
  связанные с ним записи: учитывай это при миграции.

См. [подчинённый регистр](https://1cmycloud.com/console/help/element/10.0/docs/topics/subordinated-information-register/)
и [свойства регистра](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/ProjectElements/Std/ProjectElements/InformationRegister/).

## Правила

- Правила `Ведущее`, фильтра по измерениям и ключа ниже относятся к независимому регистру. У подчинённого регистра используй правила отдельного раздела выше.
- `Периодичность` — определяет, хранится ли история: `Непериодический` (одна запись на ключ), `День` / `Месяц` / `Момент` (история по времени). Для периодического регистра `Период` также входит в ключ записи.
- Все измерения образуют ключ записи; он уникален в пределах регистра. Порядок измерений определяет порядок полей индекса основной таблицы.
- `Ведущее: Истина` — только для измерения со ссылочным типом: при удалении соответствующего объекта из базы данных запись регистра удаляется каскадно.
- Для каждого ссылочного измерения без каскадного удаления явно указывай `Ведущее: Ложь`, поскольку значение свойства по умолчанию — `Истина`.
- Каскадных измерений может не быть; значение `Ведущее` не меняет состав ключа, который образуют все измерения.
- `Измерения` — определяют разрезы, по которым хранятся данные
- `Ресурсы` — хранимые значения (что хранится)
- `Реквизиты` — дополнительные поля записи, не входящие в ключ

## XBSL паттерны

Для подчинённого регистра используй отдельный паттерн D1 в
`xbsl-pattern-register/references/движения-рс.md`. Паттерны C1–C4 ниже
относятся к независимому регистру.

### Запрос среза последних (для периодических регистров):

```xbsl
@ВПодсистеме
метод ПолучитьПоследнееЗначение(Измерение: <Справочник>.Ссылка): Число?
    знч Запрос = Запрос{
        ВЫБРАТЬ ПЕРВЫЕ 1
            Таблица.<Ресурс> КАК Значение
        ИЗ
            <ИмяРегистра>.СрезПоследних() КАК Таблица
        ГДЕ
            Таблица.<Измерение> == %Измерение
    }
    возврат Запрос.Выполнить().ПервыйИлиНеопределено()?.Значение
;
```

### Удаление записи по ключу:

```xbsl
знч КлючЗаписи = новый <ИмяРегистра>.КлючЗаписи(
    <Измерение> = Значение
)
Удалить(КлючЗаписи)
```
