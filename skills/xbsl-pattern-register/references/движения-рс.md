# Паттерны: регистр сведений

Паттерны C1–C4 ниже относятся к **независимому** РС. С платформы 10.0
доступен отдельный режим `РежимЗаписи: ПодчинениеРегистратору` (паттерн D1).

Ключевые особенности независимого РС:
- Нет `ВидЗаписи` и стандартного `Регистратора`
- Фильтр — по **измерениям** (реквизиты в фильтр НаборЗаписей не входят)
- `Записать(Замещать: Булево = Истина)` — управляет поведением при конфликте ключей
- `Период` в `ДобавитьЗапись` — **только** для периодических регистров (`Периодичность != Непериодический`)
- Виртуальная таблица для периодических — `.СрезПоследних()`
- В target 10.0 не обращайся к `РегистрСведений.КлючЗаписи.КлючОсновногоФильтра`: свойство удалено из общего ключа записи. У конкретного независимого РС одноимённое свойство может быть доступно, но для подчинённого РС его не используй. Фильтр набора записей из C1–C3 или D1 остаётся основным паттерном. [Контракт 10.0](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/Std/InformationRegisters/InformationRegister.RecordKey_ru/).

## Паттерн C1: Запись / обновление данных

Замещает существующие записи, попадающие в фильтр (поведение по умолчанию):

```xbsl
знч ЗаписиРегистра = новый <ИмяРегистра>.НаборЗаписей()
ЗаписиРегистра.Фильтр.Установить(<Измерение> = <Значение>)

ЗаписиРегистра.ДобавитьЗапись(
    <Измерение> = <Значение>,
    <Ресурс>    = <Значение>
)

ЗаписиРегистра.Записать()   // Замещать = Истина по умолчанию
```

Для **периодического** регистра — добавь `Период` (тип `Дата`, без времени):
```xbsl
ЗаписиРегистра.ДобавитьЗапись(
    Период      = <ДатаВремя>.Дата,   // .Дата усекает время
    <Измерение> = <Значение>,
    <Ресурс>    = <Значение>
)
```

## Паттерн C2: Добавить без замены существующих

`Замещать = Ложь` — новые записи добавляются, существующие по тому же ключу **не трогаются**:

```xbsl
знч ЗаписиРегистра = новый <ИмяРегистра>.НаборЗаписей()
ЗаписиРегистра.Фильтр.Установить(<Измерение> = <Значение>)

ЗаписиРегистра.ДобавитьЗапись(
    <Измерение> = <Значение>,
    <Ресурс>    = <Значение>
)

ЗаписиРегистра.Записать(Замещать = Ложь)
```

---

## Паттерн C3: Удалить записи по фильтру

Пустой набор с инициализированным фильтром удаляет все записи, попадающие в фильтр:

```xbsl
знч ЗаписиРегистра = новый <ИмяРегистра>.НаборЗаписей()
ЗаписиРегистра.Фильтр.Установить(<Измерение> = <Значение>)
ЗаписиРегистра.Записать()   // пустой набор = удаляет все по фильтру
```

## Паттерн C4: Срез последних (только периодический регистр)

Получить актуальное значение ресурса на текущий момент:

```xbsl
знч Запрос = Запрос{
    ВЫБРАТЬ ПЕРВЫЕ 1
        Таблица.<Ресурс> КАК Значение
    ИЗ
        <ИмяРегистра>.СрезПоследних() КАК Таблица
    ГДЕ
        Таблица.<Измерение> == %<Значение>
}
возврат Запрос.Выполнить().ПервыйИлиНеопределено()?.Значение
```

Можно передать дату среза параметром в `СрезПоследних()`:
```xbsl
<ИмяРегистра>.СрезПоследних(<Дата>)
```

## Паттерн D1: подчинённый РС (10.0+)

Применяй только к регистру с `РежимЗаписи: ПодчинениеРегистратору` и
`Реквизиты[].Имя: Регистратор` типа `<Документ>.Ссылка?`. Фильтр набора
содержит **только Регистратор**. Передавай ссылку документа в `Установить()`,
а не в `ДобавитьЗапись()`; измерения и ресурсы передаются в `ДобавитьЗапись()`.

```xbsl
знч ЗаписиЦен = новый ЦеныТоваров.НаборЗаписей()
ЗаписиЦен.Фильтр.Установить(Регистратор = Ссылка)
ЗаписиЦен.ДобавитьЗапись(
    Период = ДатаДокумента.Дата,
    Товар = ТоварСсылка,
    Цена = НоваяЦена
)
ЗаписиЦен.Записать()
```

`Период` включай только для периодического регистра. Перед повторной записью
проверь требуемую семантику замены движений документа: `Записать()` по
умолчанию замещает записи установленного фильтра. Не применяй фильтр C1–C3
по измерениям к подчинённому регистру. `Активность` — системное свойство
записи; для всего набора доступен `УстановитьАктивность()`.

[Документация набора записей](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/DeveloperName/ProjectName/SubsystemName/SubordinatedInformationRegisterName.RecordSet_ru/)
и [его фильтра](https://1cmycloud.com/console/help/element/10.0/docs/stdlib/element/xbsl/DeveloperName/ProjectName/SubsystemName/SubordinatedInformationRegisterName.RecordSet.Filter_ru/).

## Типичные ошибки (не делай так)

### ❌ Забыть инициализировать фильтр

```xbsl
// НЕВЕРНО: фильтр не инициализирован — платформа выдаст ошибку
знч ЗаписиЦен = новый ЦеныТоваров.НаборЗаписей()
ЗаписиЦен.ДобавитьЗапись(Товар = ТоварСсылка, Цена = 100)
ЗаписиЦен.Записать()
```

```xbsl
// ВЕРНО: Установить() без аргументов = пустой фильтр (все записи)
// Установить(Товар = ТоварСсылка) = фильтр по конкретному измерению
знч ЗаписиЦен = новый ЦеныТоваров.НаборЗаписей()
ЗаписиЦен.Фильтр.Установить(Товар = ТоварСсылка)
ЗаписиЦен.ДобавитьЗапись(Товар = ТоварСсылка, Цена = 100)
ЗаписиЦен.Записать()
```

---

### ❌ Указать Период для непериодического регистра

```xbsl
// НЕВЕРНО: Периодичность = Непериодический, но указан Период — ошибка компиляции
НаборЗаписей.ДобавитьЗапись(
    Период  = Дата.Сейчас(),   // ← нет такого поля у непериодического РС
    Товар   = ТоварСсылка,
    Цена    = 100
)
```
